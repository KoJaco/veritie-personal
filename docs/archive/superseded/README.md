# Superseded Documentation

This directory holds full copies of documentation superseded during the domain-agnostic migration.

Short redirect stubs remain at the original paths under `docs/contracts/` and `docs/architecture/` so older links still resolve to the current canonical document.

Do not use archived copies as implementation guidance unless you are researching migration history.

## Layout

- `contracts/` — retired route and model contracts from the previous product build
- `architecture/` — retired dashboard/framework architecture notes
- `decisions/` — retired routing decisions for removed surfaces
- `branch-plan.md` — historical feature branch plan from the previous product build
