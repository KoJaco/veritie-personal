# TODO

Document ADR for context rail layout with all pages.

- Context rail pinnable from lg and up only.
- Context rail is only a sheet from md -> lg.
- Context rail is only a drawer up to md.

- Context rail should be pinned to main content of each page and push ONLY main content width, not the header of the page.

This does two things:

1. It preserves the header actions and metadata per page.
2. It visually aligns the context rail to the main content of the page. Since this is an AI first product and we want the AI to be able to operate on page content and to answer questions pertaining to the page content, I think a good strategy is for it to be quite clear these two things are interlinked.
